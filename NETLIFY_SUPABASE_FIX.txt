TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════════

Problem: "Can't find SUPABASE_PUBLISHABLE_KEY in Supabase dashboard"

Solution:
- It's called "anon public" key in Supabase
- Go to: Project Settings → API
- Look for "Project API keys" section
- Copy the "anon public" key (the long one starting with eyJ)

Problem: Still getting the error after adding variables

Solution:
- Make sure you clicked "Save" for each variable
- Make sure you selected "All deploys" as the scope
- Clear cache and redeploy (don't just redeploy)
- Check the deploy log to see if variables are being loaded

Problem: Variables not showing in deploy log

Solution:
- Variables starting with VITE_ are visible in logs
- Others (like SUPABASE_URL without VITE_) might not show but are still there
- Check your Netlify deploy logs for "Environment variables"

═══════════════════════════════════════════════════════════════════════════════
WHY THIS HAPPENS:
═══════════════════════════════════════════════════════════════════════════════

- Your LOCAL .env file works fine on your computer
- But .env files are NOT pushed to GitHub (they're in .gitignore)
- Netlify builds from GitHub, so it doesn't have your .env file
- You must manually add environment variables in Netlify dashboard
- This is a security feature - keeps secrets out of GitHub!
