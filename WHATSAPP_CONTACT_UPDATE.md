## 📱 How Contact Form Works Now

### User Experience:

1. User fills out contact form:
   - Name
   - Email
   - Phone
   - Company
   - Message

2. Clicks "Send enquiry"

3. WhatsApp opens in new tab/window

4. Message is pre-filled with:
   ```
   *New Contact Form Enquiry*

   *Name:* John Doe
   *Email:* john@example.com
   *Phone:* 0123456789
   *Company:* ABC Corp

   *Message:*
   I need a quote for...
   ```

5. User clicks send in WhatsApp

6. Message arrives at **+27 76 676 8658**
