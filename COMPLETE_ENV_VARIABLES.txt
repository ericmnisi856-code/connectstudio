WHY YOU NEED BOTH VERSIONS (with and without "VITE_")
═══════════════════════════════════════════════════════════════

- Variables WITHOUT "VITE_" = Server-side code only
- Variables WITH "VITE_" = Client-side code (browser)

Your app uses BOTH:
- Server functions need: SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY
- Browser code needs: VITE_SUPABASE_URL, VITE_SUPABASE_PUBLISHABLE_KEY

If you're missing either version, parts of your app will break!
